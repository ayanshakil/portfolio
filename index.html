Things I've built

AskYourBook

GitHub ↗

A "chat with your PDF" backend in Go. A REST API ingests PDFs, splits them into chunks, generates embeddings concurrently with goroutines and indexes them in Qdrant. Queries are embedded with the same model, the top-k pages are retrieved by cosine similarity and passed to an LLM for grounded, multi-turn chat.

  1. PDFIngest via REST
  2. ChunkSplit text
  3. EmbedFan-out goroutines
  4. QdrantVector index
  5. Top-kCosine search
  6. LLMGrounded answer
